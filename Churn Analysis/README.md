# 📉 Churn Analysis Dashboard

## 📊 Overview
This project presents an interactive **Churn Analysis Dashboard** designed to analyze customer behavior, identify churn patterns, and uncover key factors affecting customer retention.

The objective is to transform raw customer data into **actionable insights** that help businesses reduce churn and improve customer loyalty.

---

## 🚀 Key Insights
- 👥 Total Customers: 1000  
- ⚠️ Churn Rate: 77.60%  
- ⏱ Avg Days Since Last Login: 195.79  
- ⭐ Avg Customer Feedback: 5.48  
- 🔴 High-Risk Customers: 33  

---

## 🔍 Dashboard Features
- **Churn Status Overview** – Active vs Churned customers distribution  
- **Churn by Subscription Type** – Monthly, Quarterly, Yearly comparison  
- **Age Group Analysis** – Churn behavior across different age groups  
- **Customer Retention Funnel** – Drop-off analysis across engagement stages  
- **Churn Trend Over Time** – Monthly churn pattern tracking  
- **Customer-Level Data Table** – Detailed user-level insights
